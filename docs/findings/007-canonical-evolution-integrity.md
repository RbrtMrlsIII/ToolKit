# 007 — Canonical Evolution Integrity

**XXX:** 007-canonical-evolution-integrity  
**Field:** Foundation / Governance  
**Status:** OBSERVED  
**Scope:** Universal Toolkit only

## Baseline

006 is frozen. Its knowledge-promotion lifecycle established that reusable lessons may become candidates only after validation and become permanent knowledge only after endorsement.

## Finding

The 005 incident proved that rigid canonical-shape protection is useful for catching accidental loss, but permanent governance must distinguish accidental deletion from authorized migration or retirement.

## Target behavior

Unexplained canonical loss remains fail-closed. Authorized migration/retirement must declare source path, removed headings, authority, semantic scope, evidence, and either a successor/target or retirement reason.

## Boundary

This slice changes only universal canonical-governance machinery. It does not authorize consumer-specific Product Law, provider/runtime choices, credentials, or downstream repository changes.

## Non-goals

No PRODUCT-KNOWLEDGE endorsement occurs in this slice. No existing canonical content is intentionally removed by the 007 implementation itself.
